# Buzzy Weather

Современный и удобный погодный дашборд, предоставляющий точные прогнозы погоды для городов по всему миру. Проект использует данные Open-Meteo API и предлагает интуитивно понятный интерфейс с поддержкой нескольких языков.

### Основные возможности:
*   **Точные прогнозы:** Почасовой прогноз на 48 часов и ежедневный на 7 дней.
*   **Многоязычность:** Полная поддержка русского и английского языков.
*   **Умный поиск:** Быстрый поиск городов с предложениями и автоматическим выбором лучшего совпадения.
*   **Приватность:** Безопасное логирование посещений и поисковых запросов.
